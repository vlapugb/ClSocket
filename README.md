# Проект: Trajectory Transmission via UDP Sockets

Данный проект представляет демонстрационное приложение на C++, которое осуществляет передачу данных траектории по сети с использованием UDP-сокетов. Программа общается с ГРУ-платой, подключенной к USB-порту, запрашивая информацию об API-версии, версии программного обеспечения (SW revision) и состоянии платы ГРУ, а также осуществляет загрузку и скачивание траектории градиентного усилителя.

## Особенности

- **Запрос информации:** Возможность запрашивать:
  - API версию устройства
  - Версию программного обеспечения
  - Состояние GRU
- **Передача траектории:** Программа считывает данные траектории из файла, загружает их на сервер и затем запрашивает скачивание.
- **Кроссплатформенность:** Поддержка работы как на Windows (с настройкой кодовой страницы консоли с помощью `SetConsoleCP`/`SetConsoleOutputCP`), так и на Linux/Unix-подобных системах.
- **Работа с файлами:** Считывание координат из текстового файла, а также сохранение полученных данных в текстовом формате.
